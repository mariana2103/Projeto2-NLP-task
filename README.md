# Projeto 2 — Help the doctor (classificação de especialidades médicas)

| Pasta | Conteúdo |
|---|---|
| `data/` | `train.csv` e `test_no_labels.csv` (teste limpo do Fenix, 398 casos) |
| `notebooks/` | `notebook1_dados_baselines` (pessoa 1), `notebook2_modelo_S1_augmentation` (pessoa 2), `notebook3_semantico_resultados` (pessoa 3) |
| `results/` | Saídas de cada notebook (`notebook1/`, `notebook2/`, `notebook3/`). O `results.txt` final fica na raiz |
| `relatorio/` | `main.tex` + `biblio.bib` (estrutura do template, para o Overleaf) |
| `docs/` | Enunciado e template original |

Ordem: notebook 1 → notebook 2 → notebook 3 → relatório. Os notebooks correm a partir de `notebooks/` ou da raiz.
Antes de submeter: o `results.txt` tem uma etiqueta por linha, sem cabeçalho, pela ordem do teste limpo, e no zip não vão modelos.
